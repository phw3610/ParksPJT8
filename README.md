# Screen Recorder

화면을 H.264 MP4로 녹화하는 Windows 프로그램. 설치·외부 도구 없이 exe 하나로 동작합니다
(.NET Framework 4.8 + Windows 내장 Media Foundation).

```
dotnet build -c Release
bin\Release\net48\ScreenRecorder.exe          # 창으로 시작
bin\Release\net48\ScreenRecorder.exe --tray   # 트레이에 숨겨서 시작
```

## 사용
- **녹화 시작/중지** 버튼, 또는 전역 단축키(기본 `Ctrl+Shift+F9`, 창에서 변경).
- 창을 닫아도 트레이에서 계속 실행됩니다. 종료는 트레이 아이콘 우클릭 → 종료.
- 저장 위치 기본값: `내 비디오\ScreenRecorder`. 설정: `%AppData%\ScreenRecorder\settings.cfg`.
- 비트레이트·프레임·캡처 방식·하드웨어 가속·추가 압축과 단축키·API 설정은 창 아래 **기타 옵션 열기**를 누르면 나옵니다(다시 누르면 접힙니다).

## 예약 녹화
상태줄 오른쪽의 **예약 녹화** 버튼에서 정합니다. Windows 시계(PC 현재 시각)와 비교해 자동으로 시작·종료합니다.
- **한 번**: 시작 날짜·시각 ~ 종료 날짜·시각. 끝나면 예약이 사라집니다.
- **요일 반복**: 월~일 중 요일을 고르고 시작·종료 시각을 정하면 매주 그 시간에 녹화합니다.
  종료가 시작보다 이르면 다음 날 종료합니다(예: 금 22:00 → 02:00).
- 예약은 설정 파일에 저장되어 프로그램을 다시 켜도 유지됩니다. 해제는 대화창의 **예약 해제**.
- 시작 시각이 지났어도 종료 전이면 바로 시작합니다. 이미 직접 녹화 중이면 그 회차는 건너뛰고,
  직접 시작한 녹화는 예약 종료 시각에 멈추지 않습니다.
- 프로그램이 실행 중이어야 합니다(창을 닫아 트레이에 있어도 됩니다). PC가 꺼져 있거나 절전이면 녹화되지 않고,
  **잠금 화면이면 검은 화면이 녹화됩니다.**

## 추가 압축 (선택, ffmpeg)
`ScreenRecorder.exe`와 **같은 폴더에 `ffmpeg.exe`가 있으면** 녹화 설정의 **추가 압축**에서 안 함 / 원본 교체 / 원본 유지를
고를 수 있습니다. 없으면 그 자리에 **ffmpeg 받기** 버튼이 보이고, 누르면(확인 후) gyan.dev(ffmpeg.org가 안내하는 Windows 빌드
배포처)의 최신 `ffmpeg-release-essentials.zip`(약 115MB)을 받아 게시된 SHA-256과 대조한 뒤 `ffmpeg.exe`만 프로그램 옆에 저장하고
바로 선택 항목으로 바뀝니다. 직접 받아 같은 폴더에 두어도 됩니다(다시 시작하면 인식). ffmpeg 없이도 녹화는 그대로 동작합니다.
프로그램 폴더에 쓸 수 없으면(예: Program Files) 받기가 실패하니 쓰기 가능한 폴더에서 실행하세요.
- 켜면 녹화가 끝난 뒤 x264(`-preset slow -crf 28`)로 다시 인코딩합니다. 화면 녹화는 보통 용량이 약 1/5~1/15로 줄고
  화질 차이는 거의 없습니다(테스트: 30초 9.7MB → 1.9MB, SSIM 0.995). 프레임 수·fps는 원본과 같습니다.
- 녹화 중에는 CPU를 쓰지 않고, 녹화가 끝난 뒤 낮은 우선순위로 한 파일씩 처리합니다. 30초 영상에 약 2초 걸렸습니다.
- **원본 교체**: ffmpeg가 성공하고 결과가 더 작을 때만 원본을 대체합니다. 실패하거나 작아지지 않으면 원본이 그대로 남습니다.
- **원본 유지**: 압축본을 `이름-small.mp4`로 따로 저장하고 원본은 그대로 둡니다(디스크를 더 씁니다).
- 압축 중 프로그램을 종료하면 압축을 취소하고 원본을 남깁니다.
- ffmpeg는 https://www.gyan.dev/ffmpeg/builds/ 의 `ffmpeg-release-essentials.zip` 안 `bin\ffmpeg.exe`를 쓰면 됩니다(x264 포함).

## 화질 설정
| 항목 | 설명 |
|---|---|
| 해상도 | 원본 / 가로 1920·1280·960·640 으로 축소 |
| 화질 / 비트레이트 | 저용량 1500 · 균형 3000 · 고화질 6000 · 최고 12000 kbps, 직접 입력 가능 (300~20000) |
| 프레임 | 1~30 fps (기본 10) |
| 파일당 최대 용량 | 넘으면 새 파일(`-2`, `-3` …)로 이어서 녹화 |

비트레이트는 용량 상한으로 동작합니다. 1080p 화면 기준 비트레이트 3000kbps에서 10fps면 정지 화면은
약 1.9Mbps(분당 약 14MB), 15fps면 약 2.3Mbps입니다. 더 줄이려면 fps·해상도·비트레이트를 낮추세요.

## API (선택)
창에서 **API 사용**을 켜면 `127.0.0.1:<포트>`(기본 47800)에서 대기합니다. 이 PC에서만 접속되며
**토큰이 필요합니다**(창의 토큰 칸에서 복사). 토큰이 없거나 틀리면 401입니다.

| 엔드포인트 | 동작 |
|---|---|
| `/start` | 녹화 시작. 쿼리로 이번 녹화만 설정 덮어쓰기: `screen` `scale` `kbps` `fps` `mb` |
| `/stop` | 녹화 중지 |
| `/toggle` | 시작/중지 전환 |
| `/status` | 상태 JSON (`recording` `seconds` `frames` `capture` `bytes` …) |
| `/folder` | 저장 폴더 열기 |

토큰 전달: `?token=…` 또는 `X-Token: …` 또는 `Authorization: Bearer …`

```
curl "http://127.0.0.1:47800/start?token=TOKEN&scale=1280&kbps=2000&fps=10"
curl "http://127.0.0.1:47800/status" -H "Authorization: Bearer TOKEN"
curl "http://127.0.0.1:47800/stop?token=TOKEN"
```

## 성능
- 화면은 GPU(DXGI Desktop Duplication)로 캡처합니다. 2560×1440에서 30fps가 그대로 나옵니다
  (GDI는 이 PC에서 예전에는 프레임당 약 150ms라 6fps가 한계였고, 지금은 모니터 DC 복사로 약 30fps까지 나옵니다).
- 인코더는 GPU 하드웨어 인코더를 우선 쓰고(없거나 거부하면 소프트웨어), 저지연 모드로 동작합니다.
  녹화 중 메모리는 약 240MB입니다(기본 모드는 1.1GB가 넘었습니다).
- DXGI를 못 쓰는 상황(잠금 화면, 일부 원격 세션 등)에서는 GDI로 대체되고, 창 상태줄에
  "GDI 캡처"가 표시됩니다. `/status`의 `capture` 값으로도 확인할 수 있습니다.

## 화면이 검게 녹화될 때
**기타 옵션 열기**를 눌러 나오는 두 가지 호환 옵션을 하나씩 바꿔 가며 시험해 보세요(녹화 중에는 바꿀 수 없습니다).
- **캡처 방식**: 자동(GPU 화면 복제 DXGI, 안 되면 GDI) / **Windows**(Windows 그래픽 캡처, 10 1903 이상) / **GDI**(가장 오래된 방식).
  앱 창이 GPU 가속으로 그려져 DXGI에서 검게 나오는 경우 Windows 방식이 해결해 주는 일이 있습니다. GDI는 경로가 달라
  다른 방식이 모두 검게 나올 때 쓰며, GDI도 이 PC에서 2560×1440 약 30fps가 나옵니다(모니터 DC에서 복사, 예전 방식은 약 7fps).
  Windows 방식은 자동과 같은 속도(30fps)가 나옵니다.
- **하드웨어 가속**: "GPU 인코더 사용"을 끄면 소프트웨어 H.264 인코더만 씁니다. 그래픽 드라이버의 인코더가 검거나 깨진 영상을
  만들 때 해결됩니다(메모리 약 100MB 증가, CPU 사용 증가).
- **저작권 보호(DRM) 영상**(넷플릭스 등)과 캡처를 막아 둔 창은 어느 방식에서도 검게 나오고, 이 프로그램은 이를 우회하지 않습니다.
  잠금 화면도 검게 나옵니다(아래).

## 알아둘 점
- **PC 잠금 화면은 녹화되지 않습니다**(검은 화면). Windows가 일반 프로세스의 보안 데스크톱 캡처를 막습니다.
- 마우스 커서는 포함됩니다. 소리는 녹음하지 않습니다(MP4에 오디오 트랙이 없습니다).
- 해상도가 매우 크면 H.264 인코더가 거부할 수 있습니다(시작할 때 오류가 표시됨). 그땐 해상도 축소를 쓰세요.
- 종료할 때 녹화 중이면 파일을 마무리한 뒤 닫습니다. 프로세스를 강제 종료하면 그 MP4는 재생되지 않을 수 있습니다.
